# Cisco NetAcad - Introduction to Networks (ITN)

Study notes from the Cisco Networking Academy **Introduction to Networks (ITN)** course, written as part of my CCNA preparation.

> **Status:** Completed
> **Next:** [Jeremy's IT Lab CCNA 200-301](../02_jeremy_it_lab_200_301/)

---

## About

These notes were written while working through the ITN modules, labs, quizzes, and final exam review. Each file covers one topic, lab, or review session, so they can be read in order or looked up individually.

## What the notes contain

- **Concept notes**: summaries of each module in my own words
- **Packet Tracer labs**: walkthroughs and verification steps
- **Quiz and exam reviews**: questions I missed, why the correct answer is right, and key takeaways
- **Final exam review**: consolidated key concepts

## Topics covered

- Network fundamentals and communication basics
- Protocols and the TCP/IP and OSI models
- Physical layer and network media
- Data link layer and Ethernet
- IPv4 and IPv6 addressing, subnetting
- ARP, ICMP, ping, and traceroute
- Transport layer (TCP/UDP) and port numbers
- Application layer services (DNS, DHCP, and others)
- Network security fundamentals
- Cisco IOS basic configuration and verification

## File naming

```
NNN_topic_description.md
```

- `NNN` is a three-digit sequence number that follows the order I studied the material.
- Names use lowercase and underscores so the files sort in study order.
